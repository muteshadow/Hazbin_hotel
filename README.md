## 🛠 Tecnologías
- HTML5  
- CSS3 (Flexbox, Grid, media queries, animations)  
- JavaScript  

## 📱 Descripción
Este proyecto fue realizado durante mis estudios como práctica de diseño web y maquetación.
Incluye una página completa con secciones, animaciones y adaptación a distintos tamaños de pantalla.

## 🎨 Diseño
El diseño se basa en un estilo visual fuerte, colores contrastantes y una atmósfera inspirada
en la estética de la serie.

📌 Proyecto con fines educativos.
